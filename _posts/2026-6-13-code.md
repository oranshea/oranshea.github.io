# 文学编程测试：Hello World

我们用文学编程的方式逐步构造一个 C 程序。

最终目标是生成 hello.c。

—

# 1. 引入标准库

所有 C 程序都需要标准输入输出库。

``` c
#include <stdio.h>
```

—

# 2. 主函数结构

定义程序入口 main 函数。

``` c
int main() {
```

—

# 3. 输出 Hello World

在主函数中打印字符串。

``` c
printf("hello world!\n");
```

—

# 4. 结束函数

返回 0 表示程序正常结束。

``` c
  return 0;
}
```

—

# 说明

运行 tangle 后生成的 hello.c 是：

``` text
#include <stdio.h>

int main() {
  printf("hello world!\n");
  return 0;
}
```
